GDD v0.5 —《乱码与卡牌 / Static & Signal》

v0.3 修订说明
在 v0.2 基础上做两项核心调整：

作业评分系统重写：去掉 SotS 式边缘符号匹配（与卡牌视觉不符），改为"brief 主题命中 + 卡牌类型多样性"双维度评分
电话场景升级为文化冲突的机制载体：电话不再只是免费产卡，而是要求玩家从牌库分享抽象/融合卡——纯母语 deck 在电话场景失败

主题、情感底色、卡牌三态视觉、三结局结构维持不变。

v0.3.1 原型迭代修订（2026-04-26）
以下三项调整来自第一轮机制原型 playtest 前的范围收窄：

牌库容量 12 → 10：8 张母语卡 + 2 个空位。缩减后每日获卡压力更明显，丢牌决策更早到来。
日循环 7 天 → 5 天：vertical slice 周期缩短，单次游玩节奏更紧凑；完整版相应调整为 3 × 5 天。
合成操作改为玩家手动选牌：点击"Synthesize"后弹出选牌弹窗，玩家自行指定 1 张抽象卡 + 1 张具象卡组合。配对有限制：具象卡的隐藏 tag 必须与抽象卡的符号一致才能融合（例：tag=◻ 的具象卡只能与 ◻ 抽象卡配对）。不匹配的卡在弹窗中变灰不可点选。后期可通过配表进一步限制或扩展合法组合。

v0.4 机制修订（2026-04-26）
本版本对合成系统做核心重设计，引入失败产出路径与扩展符号集：

抽象符号从 4 扩展到 6：新增 ✚（Structural Cross）和 ⬡（Cellular Pattern），共 ◻ ⚪ △ ◇ ✚ ⬡ 六种。
具象卡新增"形态轮廓"字段（contour）：contour 是具象卡的隐藏形态属性，默认与 tag 相同，后期可独立配表。contour 是合成匹配的依据，tag 仍只用于作业主题评分。
合成系统：从"匹配才可选"改为"任意可选，结果不同"：移除弹窗中的变灰限制，所有卡对均可点选。若 concrete.contour = abstract.sym → 产出融合卡（正常路径）；若不匹配 → 产出强行套壳卡（失败卡，−10 pts）。
作业评分：命中阈值从 ≥2 调整为 ≥3，且提交手牌中每张失败卡额外扣 10 分。
起始牌库预置 1 张融合卡（🍊 外婆的厨房 + ⚪ Negative Space），展示成功合成样本；牌库从 9/10 开始。

v0.5 机制修订（2026-05-06）
本版本对电话与上网两个场景做核心重设计，把"中英同事件"作为贯穿主线显式化：

电话场景：从"分享卡"重构为"通话对象 × 多轮换卡"——设计爸爸/妈妈/朋友三类通话对象，每轮需投入多张卡；听懂度决定产出融合、具象或抽象卡；强化沟通质量与牌库结构的关系。
上网行为：从单次 2 精力换 1 张具象卡升级为"独立检索小游戏"——每次需投入 2–5 张卡作为"检索包"，结果三分（命中复合卡 / 全损 / 偏航成普通抽象卡）；引入 ForeignNoise 跨语境干扰参数与玩家可见的概率/风险预估。
主线显式化：外部系统（课堂、上网）→ 主要产出抽象卡 X；内部经验（电话、宿舍、日常）→ 主要产出具象卡 Y；Homework 转译层把 X 与 Y 合成为融合卡 X·Y（或失败卡）。所有产出渠道围绕这一主线对齐。
1. 核心概念（30 秒版）

你是一个刚到英国的研究生。每天 15 点精力。

上午必须去上课——导师讲话是逐词滚过的乱码，30 秒实时倒计时，你只能捕获其中几个词。
下午地图打开，你自己决定剩余精力怎么花：去公园观察、上网搜索、给家里打电话，或者回房间把素材合成成卡牌。
每周交一次作业，按 brief 主题组牌。
听课捕获越多 → 抽象卡越多；打电话越多 → 具象卡越多。
牌库容量恒定。有些东西必须被丢掉。
纯母语 deck 在作业上失败；纯外语 deck 在电话上失败。中间路线最累。

机制：

3.1 一个待 playtest 的关键设计问题

玩家凭什么知道该捕获哪个词？

三个候选方案，倾向方案 C：

方案 A（纯随机）：所有乱码词等价。玩家瞎猜。→ 破坏玩家能动性，不推荐。
方案 B（明示标注）：重要词高亮显示。→ 破坏"听不懂"的体验内核。
方案 C（弱暗示）：部分乱码词有微弱视觉差异（略大、略亮、出现略慢），但暗示不完全可靠——有时高亮的也是垃圾词。玩家在游戏过程中逐渐学会读这些暗示，命中率提升不是靠角色升级，而是靠玩家自己习得模式。

方案 C 让"语言习得"这件事真的发生在玩家身上，而不是被参数模拟出来。但需要 playtest 调暗示强度。

4.3 电话场景：通话对象 × 多轮换卡

**电话场景的核心机制不是产卡，而是承担"和家人渐行渐远"这一主题。**电话消耗 0 精力，但要求玩家用手牌与不同的通话对象进行多轮互动，牌库结构直接影响沟通结果。

电话仍然 0 精力消耗——它的代价从来不在精力，在牌库构成与手牌组成。它与作业系统形成双向夹击：

作业要求多样性（含具象卡） → 纯抽象 deck 在作业上失败
电话要求至少一些抽象/融合卡 / 出得起手牌 → 纯母语 deck 在电话上失败
中间路线最累，但唯一两边都不失败
4.3.1 通话对象规则

电话不再是无差别“分享一张卡”，而是根据通话对象设计不同的投入要求和结算方式。通话对象分为三类：爸爸、妈妈、朋友。

爸爸（工作/学习向）：每轮需投入 ≥2 张卡 才能结算，单次通话最多 3 轮。推荐打出抽象卡 X（课程、方法、项目进度）或融合卡 X·Y（把学习内容说回具体情境）。每轮约 15% 概率产出融合卡；若产出融合卡则消耗本轮所有投入；若产出具象卡 Y 或抽象卡 X，则按平换结算。
妈妈（生活向）：规则与爸爸相同，但推荐出具象卡 Y（饮食、天气、作息、情绪）或融合卡 X·Y（连接日常体验与学习压力）。妈妈的产出倾向于日常主题。
朋友（全主题向）：任意 1 张卡 即可发起，单次通话最多 5 轮。首张出牌类型影响继续聊天概率：融合卡约 85%、具象卡 55%、抽象卡 45%。后续每轮必须与首轮主题相关性 ≥70%，否则朋友兴趣急速下降。听懂度高时可稳定产出融合卡；听懂度低时可能产出具象或抽象卡，或直接失败。

在每一轮通话中，听懂度（0–100）由话题相关性（50%）、卡牌类型匹配（30%）、对象偏好匹配（20%）决定。听懂度高→更可能产出融合卡；听懂度低→更可能产出具象卡或抽象卡，甚至无产出。

电话换卡仍然是合成系统的素材补给与转译辅助：补充具象素材（父母与朋友通话产出 Y）、通过沟通将抽象卡回译为具象卡、或在高听懂度下直接产出融合卡。产出的融合卡仍遵循形态同构判定 (contour == abstract.sym)；不匹配则为强行套壳卡（−10 pts）。

4.3.5 设计内涵

通话对象的设计让“和家人渐行渐远”从抽象的牌库压力落地为具体的语义差：不同对象关心不同主题，父亲听不懂生活细节，母亲不理解学术术语，朋友的兴趣随时偏离。玩家需要根据对象调整投入，用融合卡在抽象与具象之间搭桥。这个机制让玩家意识到自己的牌库里这种双语文化混合卡的稀缺，以及“翻译”和沟通本身的代价。

4.4 上网检索小游戏（独立小游戏）
4.4.0 定位

"上网"不是普通换牌动作，而是一个独立小游戏环节：

玩家需要一次性投入多张卡，进行一轮"检索 → 拼接 → 提交"的高风险合成。
目标是从信息噪声中，换出最终提交作业需要的"最符合目标的复合卡"。
结果不稳定：可能大赚，也可能亏掉整手投入。

设计目标：

让"上网"成为中后期关键决策，而非顺手操作。
强化"信息有真有假"的主题：越想走捷径，越可能被误导。
提供可读、可算、可调参的结算模型，便于数值迭代。

4.4.1 进入条件与回合结构

进入条件（示例）：消耗 1 次"上网机会"或 1 点"网络行动力"，并选择一个作业目标标签（例：历史+视觉、社会+数据）。

单次小游戏流程：

1) 选题：玩家主动选择检索主题（决定结果池倾向）。
2) 选提交目标：玩家指定本轮希望产出的复合卡方向（例如：偏理论 / 偏视觉 / 偏数据）。
3) 出牌：从手牌一次性打出 2–5 张卡（至少 2 张），形成"检索包"（Search Bundle）。
4) 检索判定：根据主题、出牌结构、噪声值生成信息结果。
5) 合成结算：产出 1 张结果卡（或无效）并处理损失，回到主流程。

4.4.2 玩家主导决策（关键点）

为避免系统代替玩家做决定，明确规定：

玩家自己决定本次提交什么卡（系统不自动推荐）。
玩家自己决定检索主题与提交目标方向（系统不强制）。
系统仅提供风险/概率反馈，不替玩家做最终选择。

提交按钮旁显示：

当前主题与目标作业匹配度（高/中/低）。
检索包结构提示（主题卡是否足够、速成卡是否过多）。
四结果概率预估（目标复合 / 一般复合 / 抽象卡 / 全损）。
失败预估损失（预计损失几张、是否可能全损）。

4.4.3 检索包（Search Bundle）出牌规则

必须同时打出多张卡（非逐张替换）。
检索包可包含三类角色：

主题卡：定义检索方向。
修饰卡：增加命中或降低风险。
速成卡：提高收益同时提高污染概率。

多卡同投是机制核心：体现"在复杂网络环境中拼凑结论"，让玩家在"投入越多潜在收益越高、爆掉时损失越大"中做抉择。

4.4.4 结算结果（四种核心结果）

每次上网小游戏结束后，结果落在以下四类之一：

A. 命中结果（目标复合卡）
获得 1 张高匹配目标复合卡（可用于最终作业提交），匹配度分 精准 / 可用 两档。

B. 次优结果（一般复合卡）
获得 1 张一般复合卡（中价值，可作为过渡提交或二次合成素材）。

C. 偏航结果（普通抽象卡）
获得 1 张普通抽象卡（低价值、与当前作业目标弱相关或无关），可作为后续合成素材。

D. 崩溃结果（全损）
本次检索包内卡片全部销毁/移出；可附带 1 层"信息过载" Debuff（下次上网更危险）。

4.4.5 概率模型与动态修正

P_target + P_general + P_abstract + P_loss = 100%

建议初始值（统一基线）：

P_target = 10%
P_general = 15%
P_abstract = 50%
P_loss = 25%

动态修正项：

玩家提交卡牌越相关且信息越充分：P_target 上升，P_abstract / P_loss 下降。
使用验证类卡：P_loss −8%（可调）。
噪声值过高：P_loss +10%，P_target −5%。
速成卡数量 ≥ 2：P_target +5%，P_loss +8%。

说明：抽象卡结果应保持高频，以体现"信息很多但不一定对题"。

4.4.6 ForeignNoise（跨语境干扰）

新增变量 ForeignNoise（0–100）。
ForeignNoise 高时：

提高 P_abstract（或偏航权重）。
产出的普通抽象卡更"概念化"，更难直连作业目标。

可配套两种反制：

本地化检索：降低偏航概率。
术语校对：把一张普通抽象卡转为"半相关卡"。

4.4.7 玩家可见信息（避免“纯随机感”）

上网界面直接显示：

本次投入卡数与总风险等级（低 / 中 / 高）。
四种结果的当前概率预估（目标复合 / 一般复合 / 抽象卡 / 全损）。
风险来源说明（噪声高、跨语境高、未验证等）。

让玩家认为"我在承担可理解的风险"，而不是被暗骰惩罚。

4.4.8 MVP（最小可玩版本）

一次必须打出 3 张卡。
只产出四种结果：目标复合卡（10% 基线）/ 一般复合卡（15%）/ 普通抽象卡（50%）/ 全损（25%）。
提供一个"验证"开关：开启后 P_loss 固定下降。

该 MVP 已完整覆盖核心意图：一次性多卡投入、高收益与高损失并存、信息偏航高频。

4.4.9 三方向检索模式（玩家可选）

每次上网先从 3 个方向选 1 个进入两轮注卡：

本地活动（Local Events）
日常购物（Daily Shopping）
城市出行（Urban Transit）

三方向统一规则（首版）：

每次上网仅能选择 1 个方向，并进行 2 轮注卡。
每轮建议最少 3 张（2 具象 + 1 抽象）以保证信息拼装质量。
第二轮可基于第一轮产物继续加注，追求目标复合卡。
任一轮触发全损时，仅清空该轮投入，不影响未投入手牌。

强行套壳卡 (Forced Geometry)	Homework 合成（contour 不匹配）	几何框架与具象内容明显错位，视觉上有断裂感（错位边框 + 碰撞色）	作业提交时每张 −10 pts；无法进行电话出牌
形态崩塌卡 (Collapsed Form)	待设计（v0.6 考虑：连续失败合成 / 上网连续 Crash 后触发）	TBD	预计 −15 pts；代表彻底丧失转译能力

视觉机制即叙事：外部学术世界给你空的几何外壳，自己的生活给你温暖的具象。创作的工作是把后者变成前者的形态——但消化过程中，温度有没有被保留？强行套壳卡是"形还在，但魂没进去"的状态：几何框架与具象记忆的接缝清晰可见。

6. 牌库与作业
6.1 牌库恒定
总容量 10 张
初始牌库：8 张母语具象卡（玩家从家乡带来）+ 2 个空位
新增卡 → 必须从现有牌库选一张丢弃 / 保留 / 融合
6.2 作业评分：主题命中 + 多样性

每次作业 brief 指定一个主题符号（例如：本周作业主题是 ◻️）。
玩家提交 4 张卡（数量可在 playtest 中调整）。

A. 主题命中（Theme Match）

提交卡中至少 3 张与主题符号相关：

抽象卡 → 直接看符号是否匹配
具象卡 → 每张具象卡有隐藏的"主题 tag"（湖→ ◻️、橘子→ ⚪、猫→ △……）
融合卡 → 因为同时含具象基底和抽象符号，只要其抽象符号匹配主题即算命中
B. 多样性（Diversity）

4 张卡覆盖的"卡牌类型"数量：

4 张同类型 → 单调（最低）
2 + 2（抽象+具象 / 抽象+融合 / 具象+融合）→ 有结构（中）
1 + 1 + 2 或 全三类 → 综合（最高）
7. 具象卡示例：广东生活习惯文化

为构建可信的母语记忆池，本节列举了一组基于广东地区日常文化的具象卡示例，可作为玩家初始母语卡或电话回赠素材。分类如下：

7.1 日常饮食卡
早茶慢叹：周末早上一家人或同事去酒楼“饮茶”，一盅两件、叹茶、点心车推过，边聊边吃。
清鲜本味：家庭晚饭 2–3 道菜加老火汤，如清蒸鱼、白灼菜心、蒜蓉蒸虾，强调食材原味、少油少辣。
老火靓汤：冬瓜薏米、莲藕花生、玉米胡萝卜骨汤等老火汤，祛湿清润，是调节身体状态的日常方式。
7.2 过节习俗卡
行花街：除夕前去花市买桃花、年桔、银柳，讲究开年好意头。
派利是：春节期间和开工后派“利是”，金额不大但重在祝福与仪式感。
清明重阳：家族集中返乡祭祖、扫墓、登高，慎终追远。
冬至团圆：冬至晚饭家庭聚餐加菜、时令进补，虽不如春节隆重但亦重视团圆。
7.3 买菜习惯卡
早市买手：清晨去菜市场买当天新鲜菜，熟悉摊主，关注食材新鲜度。
时令采购：根据天气与节气调整菜谱，祛湿清热，常用薏米赤小豆等煲汤料。
7.4 商场消费习惯卡
夜间逛场：晚饭后逛商场，看电影、喝糖水、散步式消费，体现夜经济。
饭点等位：热门餐馆饭点先取号后逛商场，叫号后再回去用餐。
周末一站式：周末带娃逛商场，一站式完成餐饮、采购、亲子娱乐。
7.5 出行习惯卡
看天出行：台风季或暴雨时看天气 App，错峰出行，优先地铁。
短途高频：城市内多点位办事，组合地铁、步行、网约车、电动车短驳。
7.6 工作学习习惯卡
务实高效：工作沟通强调效率与落地，会议短平快，重执行与反馈。
交期节奏：珠三角产业链协同频繁，注重交期、样品、排产等节奏。
在职提升：夜校、线上课、职业资格考试等在职学习模式常见。
多语切换：在不同场合灵活切换普通话、粤语、英语，职场以普通话为主，家庭社交偏粤语。

这些具象卡为母语 deck 提供了丰富素材，可用于电话、上网或公园场景的产出，并在合成与作业评估中提供多样性。

C. 关键规则：融合卡的双属性

融合卡同时计入"抽象类"和"具象类"两个统计。

这让融合卡在多样性维度上以一抵二，但不能完全取代两侧。看下表：

提交组合	主题	多样性	教授评价
4 抽象	命中	单调	"Technically on-brief, but where's the work?"
4 具象	失败（无抽象主题符号）	单调	"I don't see how this engages with the brief"
2 抽象 + 2 具象	命中	中	"Some engagement, but feels collaged"
1 抽象 + 1 具象 + 2 融合	命中（多个）	高	"A clear voice working through the brief" ← 最高分
4 融合卡	命中	单调（仍是单一类型）	"Strong voice but underdeveloped — where's the rigor?" ← 故意压低

全融合策略被故意压低——理由是缺少 raw 抽象/具象的对照。这避免"全融合最优"的策略坍缩。

D. 失败卡扣分（v0.4 新增）

提交手牌中的失败卡直接从评分中扣除：

失败卡类型	每张扣分
强行套壳卡（Forced Geometry）	−10 pts
形态崩塌卡（Collapsed Form，v0.6）	−15 pts

失败卡不影响 theme match 判定（仍可命中主题），但会拉低最终评级。理性策略是：宁可不交失败卡，也不要凑数。

6.3 brief 模糊机制

如果听课捕获不足，brief 的主题符号会有部分以 "?" 显示——玩家被迫赌：

猜对了 → 主题命中加分
猜错了 → 主题命中失败，且全部命中分数清零

这对应"没听懂作业要求就开始做"的真实赌博感。

7. 三结局

通关时由牌库构成决定，无优劣关系：

Clean Slate（同化）：母语具象卡 ≤ 2，无融合卡 → 作业评价高，电话连续失败。结尾镜头：家里来电话，"我现在不太方便，晚点打回去"，挂断，flash 闪过被丢弃的母语卡。
Untranslated（坚守）：母语具象卡 ≥ 6，抽象/融合卡 ≤ 2 → 作业勉强及格，电话也接不下去。结尾镜头：自己说母语清晰，走廊里同学说话仍是乱码；电话铃响，犹豫片刻，没接。
Fluent in Two Tongues（融合）：融合卡 ≥ 3 → 双语流利，作业和电话都能维持，但这条路最累。结尾镜头：熬夜蒙太奇 + 提交作业 + 揉太阳穴 + 接起电话用母语笑着说话。

三个结局演出长度、配乐、镜头语言等量齐观。不奖励"正确路线"。

与参考作品的关系

为什么上网从"顺手换牌"升级为高风险检索小游戏？（提示：让"信息有真有假"对应到玩家行为成本）

展示 critical design literacy 是 MA 申请最值钱的部分。敢于在文档里写"我砍掉了什么、为什么砍"，比假装一切都设计完美更显成熟。

12. 设计理由：为什么不用概率失败，而用形态同构

v0.3 的合成系统是"不匹配 = 拦截（变灰不可选）"。v0.4 改为"不匹配 = 可选，但产出失败卡"。这是一个有意的设计方向选择，理由如下：

为什么不用概率失败（random chance）？

概率失败（"有 30% 概率合成失败"）在机制上诚实，但在叙事上是空洞的。玩家失败时没有任何可读信息：既不知道自己做错了什么，也没有办法学习和改进。这与游戏的核心主题（在不确定中构建理解）相悖——游戏应该给玩家留下可解读的残骸，而不是随机噪声。

为什么不用拦截（变灰不可选）？

拦截是最安全的设计：它告诉玩家"这条路不通"，防止浪费资源。但它也关上了一个叙事可能性：玩家永远不会亲眼看到强行套壳的结果是什么样的。失败卡的视觉（错位框架 + 碰撞色）是游戏叙事的一部分——"形还在，但魂没进去"这个状态需要被玩家看到、感受到，而不是被提前阻止。

形态同构的叙事逻辑：

具象卡的 contour（形态轮廓）代表它在视觉/结构层面的"潜在抽象形"。抽象卡的 sym 代表学术话语赋予的几何外壳。只有当两者一致，消化才真正发生；否则只是强行套上了一个壳——这正是国际学生在学术写作中常见的困境：用正确的词，但意思没有真正进入形式。

保留"故意选错"的可能性：

有经验的玩家可能会故意制造强行套壳卡——作为牌库管理的一种策略（消耗掉不想要的卡，换一个占位的失败卡）。这是一种合理的边缘策略，设计上不应该拦截它。

v0.5 的延伸：上网用概率三分，电话用确定分支——为什么并存？

合成保持"形态同构"（确定结果）是因为它是核心创作行为——叙事必须可读。
上网用三段概率（P_hit / P_crash / P_drift）是因为它要表现信息环境本身的不确定——但玩家可见所有概率与风险来源，不是暗骰惩罚。
电话用"卡类型 → 分支结算"（确定结果）是因为它要表现语义差是结构性的，不是运气问题——面对同一通话对象，具象、抽象、融合各自走可解读的路径。

三种结算风格各自承担不同主题：合成 = 转译能力；上网 = 信息噪声；电话 = 语义差。

13. 待 v0.6 考虑的事项（仅记录，不做）
形态崩塌卡（Collapsed Form）的触发条件：连续失败合成（如 3 次强行套壳）或上网连续 Crash 后，下次合成/检索无论是否匹配都产出崩塌卡？还是作为一种特殊的高代价行动？
contour 与 tag 的独立配表：目前 contour = tag（默认），后期可以让具象卡的 contour 不等于 tag，制造更复杂的策略空间（某张卡在主题上命中 ◻，但在形态上属于 ⚪）。
电话场景的反向冲突：家人或朋友是否能"感知到"牌库里有失败卡？失败卡是否会影响不同通话对象的对话内容？
通话对象的扩展：是否新增其他通话对象（例：老师、房东），覆盖更多语境差；或允许同一对象多次重访产出递进式回赠卡。
上网"信息过载"Debuff 的具体作用：Crash 附带的 Debuff 在下一次检索如何具体生效？提高 P_crash？锁定一个槽位？还是污染下一次抽到的具象卡？
本地化检索 / 术语校对作为可解锁的反制卡：是否作为电话事件回赠或合成产出？
